# Position layout references

The By Position catalogue uses five dedicated editable layouts. The original 22 gallery designs remain separate.

These layouts were implemented after inspecting Jobscan's published example images. Example CV wording and identities are original fictional samples. Reference images are used privately for inspection, not embedded in the published gallery.

| Layout | Inspected reference | Structure reproduced |
| --- | --- | --- |
| Position Classic | https://static.jobscan.co/blog/uploads/Administrative-resume-example.png | Right-aligned serif identity, italic contacts, plain section headings, dates aligned right |
| Position Academic | https://static.jobscan.co/blog/uploads/Junior-Accountant-Resume-Example-e1730495192138.jpeg | Centred sans-serif identity, education before work experience, plain skills and certificates |
| Position Centred | https://static.jobscan.co/blog/uploads/Business-Operations-Analyst-Resume-scaled-e1733411646687.jpg | Centred identity with experience first and an unshaded introduction |
| Position Modern | https://static.jobscan.co/blog/uploads/Senior-Software-Developer-Resume-e1733414637955.jpeg | Split identity/contact header and summary inside a pale grey introduction |
| Position Minimal | https://static.jobscan.co/blog/uploads/Attorney-resume-example.png | Split identity/contact header without shading, experience-led content |

The 152 role choices map to these five layout families by industry. They are not 152 individually reproduced Jobscan example pages. Additional inspected references include teacher, HR, marketing, nursing, pharmacy, project management, sales, writing, product design and hospitality examples.

Entering a role in the starting questions opens By Position with matching examples. Selecting a card sets its role and dedicated layout while retaining the user's CV information. The shared document renderer preserves the selected layout in editing, review and exports.


## Supplied eight-example set

Eight additional dedicated template identifiers now correspond to the supplied screenshots: Software Developer, Customer Service, Network Engineer, Medical Assistant, Human Resources, Product Manager, Nurse, and Project Manager. They appear first in By Position, with Use This Template controls. These examples use the provided sample identities and role structures, with contact emails represented using example.com.

Network Engineer places Education and Projects before Work Experience. Medical Assistant places Education first. Human Resources has an uppercase split header without a subtitle. Software Developer, Product Manager and Nurse have shaded introductions. Project Manager uses an unshaded split header with certificate dates. Selecting one preserves the user's own CV information and applies the dedicated template identifier.


## Current department gallery

The visible By Position tab has been replaced with By Department. It shows exactly ten cards, in the requested order: Admin, Human Resource, Marketing and Sale, Operation and Production, Information technology, Supply Chain and Logistics, Legal and Compliance, Public relations, Engineering, Managers. Each card has a role selector and an expandable role list. Admin lists 30 administrative and office-support roles. Department template identifiers retain their source design through design_id, so previously saved position templates also remain renderable.
